# EDUARCH
AI-Powered Multilingual Gamified Learning Platform

About the Project

EduArch is an AI-powered, gamified learning platform designed for CBSE students. It aims to make learning engaging, accessible, and interactive through animated educational videos, quizzes, gamified activities, and an AI tutor.

Problem Statement

Traditional learning methods may not meet every student's learning needs. Limited access to engaging learning resources and personalized support can create learning gaps and reduce student engagement.

Proposed Solution

EduArch combines AI-powered learning support with gamification to improve the learning experience.

Key Features

Animated Educational Videos: Explain concepts through visual storytelling.

Interactive Quizzes: Assess understanding after each lesson.

Gamified Learning: Encourage participation through interactive activities.

AI Tutor: Provide additional learning assistance.

Multilingual Learning: Support learning in English and Tamil.

Progress Tracking: Monitor quiz performance and learning progress.

Technology Stack

Frontend: React.js

Backend: Node.js and Express.js

AI Integration: Gemini API and AI-powered video generation

Development Tools: Visual Studio Code and Git

How It Works

Select a lesson and preferred language.

Learn through educational content and animated videos.

Answer questions after the lesson.

Receive feedback based on answers.

Review learning progress and strengthen understanding.

Social Impact

EduArch aims to complement classroom teaching, reduce learning gaps, and improve access to engaging educational resources.

Sustainable Development Goals

SDG 4 – Quality Education: Promote inclusive and equitable education.

SDG 10 – Reduced Inequalities: Help address learning disparities among underserved communities.
